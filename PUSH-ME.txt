วิธี push ขึ้น GitHub (ทำครั้งเดียว)
=====================================

โฟลเดอร์นี้มี git repo พร้อมแล้ว ตั้ง remote และ branch ไว้ให้เรียบร้อย
ไม่ต้อง git init ใหม่ ไม่ต้อง git add ไม่ต้อง commit

เปิด Terminal / Git Bash แล้วเข้ามาในโฟลเดอร์นี้ จากนั้นรันบรรทัดเดียว:

    git push -u origin main --force


ถ้าถาม username/password ให้ใส่:
    username = udtapidudtapid-pixel
    password = Personal Access Token (ไม่ใช่รหัสผ่าน GitHub)

วิธีสร้าง token: GitHub > Settings > Developer settings >
Personal access tokens > Tokens (classic) > Generate new token
เลือก scope "repo" แล้ว copy มาใส่ตรงช่อง password


ตรวจหลัง push เสร็จ
--------------------
    git ls-files | wc -l

ต้องได้ 51
